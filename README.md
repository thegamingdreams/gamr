# Chaos Drive 2077

A highly chaotic browser game built with vanilla HTML Canvas. You drive a neon supercar through a storm-slick cyberpunk highway full of traffic, oil slicks, explosive barrels, police drones, lightning, particles, screen shake, near-miss combos, nitro drifting, and shockwave blasts.

## Where to start it

Start the game from the repository root:

```bash
cd /workspace/gamr
npm run start
```

Then open this URL in your browser:

```text
http://127.0.0.1:5173
```

When the page loads, click **Start chaos run**.

> No `npm install` is required because the game is dependency-free and uses Python's built-in static file server through the `npm run start` script.

## Controls

- **WASD / Arrow keys**: steer and dodge
- **Shift**: nitro drift
- **Space**: shockwave blast

## Build / syntax check

```bash
npm run build
```
